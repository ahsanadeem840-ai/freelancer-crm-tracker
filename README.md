# Freelance CRM & Project Tracker 🚀

A full-stack MERN CRM for freelancers and digital agencies to manage clients, projects, and tasks in real-time. Features role-based auth (JWT), Kanban task boards, live notifications via Socket.io, and Stripe-powered invoicing. Built with React, Node.js, Express, and MongoDB — a lightweight alternative to bulky CRM tools.

---

## 🛠️ Tech Stack

- **Frontend:** React, React Router, Tailwind CSS, Axios
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose ODM)
- **Real-Time:** Socket.io
- **Payment Gateway:** Stripe API
- **Authentication & Security:** JWT (JSON Web Tokens), bcryptjs, helmet, CORS
